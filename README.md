# RescueRadar (Previously Named Emergensee)
This app is designed for Android devices and is intended to allows its users to easily call an emergency number with the press of a button, whether that be the police, or any other emergency contact.

This app was developed using Android Studio and was written using kotlin.

## Requirements

- Android Studio (latest version)
- Emulation enabled on current device or a physical Android device is nessisary to run the application in Android Studio

## User Guide

### 1. Set Up Android Studio
- Download and install Android Studio from the official website:  
  [https://developer.android.com/studio](https://developer.android.com/studio)
- Follow the setup instructions to configure the Android SDK and Emulator.

### 2. Download the Project Files
- Clone the repository and open the files in Android Studio:  

- You can either click the green **Code** button and select **Download ZIP**, or clone the repository using Git:

  ```bash
  git clone https://github.com/Knucklesfan/EmergenSee/tree/main

### 3. Open the Project in Android Studio
- Launch Android Studio.

- Select File > Open, then navigate to the folder where you downloaded or cloned the project.

- Allow Android Studio to index and build the project.

### 4. Run the App
- Connect a physical Android device or start the emulator via the Device Manager. 

**If using the emulator:** You may need to enable emulation in your device's BIOS settings to run the emulator.

**If using a physical android device:** You will need to enable USB debugging in the developer settings of your android device to run and debug the app.

- Click the green Run button in the top-right corner of Android Studio.

- The app should build and launch on the selected device.

### 5. Running the app
- When running for the first time on your android environment, you will need to open the app's "App Info" and enable the appropriate permissions for the app to work properly.
- Otherwise the app may not function as intended.
